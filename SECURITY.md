# Security Policy

## Supported Versions

| Version           | Supported          |
| ----------------- | ------------------ |
| Latest Release    | :white_check_mark: |
| Default Branch    | :white_check_mark: |

## Reporting a Vulnerability

Please report vulnerabilities privately via GitHub Security Advisories by clicking "Report a vulnerability" on this repository. **Do not** open public issues for security reports.

## Response Targets

- We aim to acknowledge your report within 5 business days.
- We aim to provide a status update within 14 days.
- We follow coordinated disclosure.
- There is no bug bounty program.
